# 常用战术与坑（务必遵守）

- ℝ 分数的类型标注：`(1/2 : ℝ)`；`norm_num`/`nlinarith` 前先 `field_simp [分母≠0]`。
- Nat 与 ℝ 混用：`exact_mod_cast`、`(m : ℝ)`。
- `Fin.sum_univ_four` 存在：`∑ j : Fin 4, f j = f 0 + f 1 + f 2 + f 3`。
- `Finset.sum_eq_single_of_mem a hmem h₀`（要求 a∈s）；`Finset.sum_eq_single` 的第二参数是 `a ∉ s → f a = 0`。
- `omega` 对含 `r - 1` 的 Nat 目标可能报 metavariable，改用 `Nat.sub_add_cancel` / `Nat.sub_lt`。
- `rw [k = (k-1)+1]` 会误改 `k-1` 内的 `k`，只改指数用 `conv_lhs => rw [← Nat.sub_add_cancel hk]`。
- `fin_cases j` 后目标里 Fin 数字形如 `(fun i => i) ⟨0, ⋯⟩`，`rw` 匹配不上，改用 `exact le_of_eq (引理)`（`exact` 走 defeq）。
- `decide` 不能处理自由变量；对 Fin 4 上的分配用 `fin_cases i <;> decide`。
- 归纳/求和：`Finset.sum_range_succ`、`Finset.sum_congr rfl`、`Finset.mul_sum`、`Finset.sum_add_distrib`。
- 多项式恒等式（mod α²−2α−2）：先 `ring_nf`，再 `nlinarith [braun_poly2]`（或先构造 α^n 的线性闭式再 nlinarith）。

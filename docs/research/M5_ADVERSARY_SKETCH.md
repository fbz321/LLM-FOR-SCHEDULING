## 建议工作流

1. **候选发现**：状态相关临界作业、CEGIS、beam/MCTS 或 LLM 只提议动作。
2. **有限精确求解**：固定有理阈值的 OR–AND reachability，使用完整状态记忆化和对称响应剪枝。
3. **独立认证**：策略 DAG 穷举全部不等价调度器响应；每个前缀的 OPT 由独立求解器或可核验 packing 证书确认。
4. **结构提炼**：从紧前缀、packing 签名和有理关系中重建参数族。
5. **Lean**：先形式化有限证书，再考虑一般参数族。
